# 09 嘴上只说总结，字照样写全

**先决条件：没有，现在就能开。** 只改对话那条路（AI 服务的标签解析、桌面端的语音和气泡），不碰编程 Agent。

## 背景

对话里她查完资料，回答常常很长（列表、链接、几段话）。现在桌面端是一边收文字一边逐句合成语音，**从头念到尾**，头顶的气泡也一路往下打字。听起来啰嗦，气泡也装不下。

要做成：**完整的文字照样写，嘴上只说开头一两句总结**，气泡也只显示这一两句。

提示词那边（让她每次回答先写一句给耳朵听的总结、整体说话更精简）由 Claude 在「人格和说话方式」里改，**这个任务不改 `aila-ai/app/persona.py`**。格式先在这里定死：

```
[happy][say]查到了，最便宜的是京东那家，三百二。细节我列在对话框里了。[/say]
1. 京东：320 元……
2. ……
```

- `[say]` 和 `[/say]` 之间是要念出来的总结，在回答的最前面（前面可以有表情、动作标签）
- 一次回答最多一段 `[say]`；短回答也可以整段包起来

## 要做的

1. AI 服务：`aila-ai/app/tags.py`
   - `TagParser` 认 `[say]`、`[/say]`（和表情标签一样可能被拆在两个数据块里，要缓冲；不在白名单里的方括号照旧原样保留）
   - 文字事件多一个字段 `spoken: bool`：`[say]` 里面的是 `true`，后面的是 `false`
   - **兜底**：一次回答开头没有 `[say]`（模型忘了），按规则标：开头的文字一直标 `spoken: true`，直到出现下面任何一种情况，之后全部 `false`：
     - 已经念了两句（句号、问号、感叹号、换行算一句结束），或者能念的字（汉字、字母、数字）超过 60 个
     - 遇到列表（行首的 `-`、`*`、`1.`）、代码块（```）、网址
   - 兜底时如果后面还有没念的内容，补一个文字事件 `{"type": "text", "text": "", "spoken": true, "hint": "more"}`，桌面端据此加一句「细节在对话框里」（文字由桌面端出，不进对话记录）
   - 规则写成能单测的纯函数；`[say]` 两个标签本身不出现在任何文字事件里
2. 桌面端
   - `src/shared/chat.ts` 的 `text` 事件加 `spoken?: boolean`、`hint?: 'more'`。**没有 `spoken` 字段时当 `true`**（老版本的 AI 服务照旧全念）
   - `src/renderer/src/chat/Conversation.ts`：
     - 只把 `spoken !== false` 的文字送去合成语音、在头顶气泡里打字（口型、表情、动作跟着念的部分走）
     - 完整文字（念的 + 不念的）照旧进对话记录（`history`，同步、对话页都用它），**不带 `[say]` 标签**
     - `hint === 'more'` 时，气泡末尾加一句「细节在对话框里」，语音也念这一句（用 `persona/lines.ts` 加的固定句子，不让模型生成）
   - 气泡：有不念的内容时，气泡上有个「看全文」，点了在气泡里展开完整文字（可以滚动），或者打开主窗口的「对话」页定位到这条——选一种做，写进结果说明
   - 关了语音（`voice.speak` 关）时：气泡照样只显示总结 +「看全文」，行为一致
3. 文档：`aila-ai/README.md` 对话部分、`aila-desktop/README.md` 语音部分写清楚这条规则；`docs/real-test-plan.md` 第 3 节（语音）加一条：问一个要查资料的问题，听到的只有一两句，对话框里是全文

## 不要改

- `aila-ai/app/persona.py`（Claude 在改提示词）
- 语音合成、分句的节奏（`voice/sentences.ts` 的切句规则不动，只是喂进去的文字变少了）
- 编程 Agent、任务页

## 验收

- `aila-ai` 新测试（可以放 `tests/test_tags.py`）：
  - `[say]` 被拆在任意位置的两个数据块里也认得出；`[say]` 前后的表情、动作标签照常
  - 没有 `[say]` 时的兜底：两句、60 字、列表、代码块、网址各一个例子；短回答（一句话）全部 `spoken: true` 而且没有 `hint`
  - 代码里的 `a[i]`、`[say` 没闭合这类不被误认
- 桌面端测试：
  - `Conversation` 只把念的部分送进合成、气泡；对话记录里是完整文字，没有标签
  - 没有 `spoken` 字段的老事件照旧全念
  - `hint: 'more'` 时多念一句固定的话，而且这句不进对话记录
