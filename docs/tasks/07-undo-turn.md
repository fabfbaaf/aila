# 07 撤销一轮：把她这一轮改的文件退回去

## 背景

编程 Agent 改文件只有两个工具：`edit_file` 和 `write_file`（`aila-ai/app/runtime/tools.py` 的 `_edit`、`_write`，最后都走 `_changed`）。改之前用户会确认，但改完发现方向不对时，现在只能自己用 git 退，没提交过的改动还退不回来。Claude Code 有「回到这一步之前」，这个任务做一个简单可靠的版本：**撤销最近一轮她用这两个工具做的所有改动**。

会话是只追加的事件日志（`runtime/session.py`，开头的说明讲了为什么），一轮从一个 `user` 事件开始、到 `turn_end` 结束。在新分支上做的会话（`session.branch`）她在临时目录里干活，`session.workdir` 是那个目录。

## 要做的

1. 改之前留底：`CodingTools` 接受一个可选的「底片存放处」（`Snapshots`，新文件 `runtime/snapshots.py`），由 `Runtime.agent()`（`runtime/runner.py`）传进去，目录是 `data/sessions/<会话 id>.snap/`（和日志放一起，不进发给模型的消息）。`_edit`、`_write` 写文件之前：
   - 已有文件：把原来的**字节**存一份（`<序号>.bin`）
   - 新建的文件：只记「这是新建的」
   - 写完以后算新内容的指纹（和 `workspace.py` 的 `_digest` 一样用 blake2b）
   - 这些信息放进工具结果的 `extra`（只给界面看，不进模型的消息）：`snap`（序号，新建的没有）、`created`、`after`（指纹）
2. 撤销：`Runtime.undo(sid)`，只撤销**最近一轮**：
   - 她还在做事时不能撤销；最近一轮没有改文件就说「最近一轮没有改文件」
   - 从后往前处理这一轮里状态是 `ok` 的 `edit_file` / `write_file`：同一个文件改了好几次，退回到这一轮第一次改之前
   - 只有文件**现在的指纹等于她最后一次写完时的指纹**才退（之后用户自己改过的，不碰，告诉用户是哪个文件）
   - 新建的文件：没被改过就删掉
   - 路径一律经过 `Workspace.resolve`（不出项目目录）；按字节写回（和 `branch.py` 合并时一样，不动换行符）
   - 结果追加一条 `undo` 事件：退回了哪些文件、哪些跳过了（为什么）
   - `run_command` 做的事（比如 `npm install`、删文件的命令）退不回来：如果这一轮里有成功执行的命令，结果里提醒一句「这一轮还跑过命令，命令做的事没有撤销」
3. 让她知道：`derive_messages` 遇到 `undo` 事件时，**不改**之前的消息（只追加，前缀缓存才能命中），而是把一句说明放在下一句用户的话前面（和会话开头的环境说明一样的做法）：「（用户撤销了你上一轮对这些文件的改动，文件已经恢复成改之前的样子：a.py、b.py。没恢复的：c.py（之后被用户改过）。）」。读过这些文件的记录要作废：撤销后她再改这些文件前必须重新读（`Workspace.seen` 里去掉这些文件）
4. 每个会话只能撤销最近一轮，撤销过的那一轮不能再撤销一次；撤销以后她又做了一轮，可以撤销那新的一轮
5. 入口：
   - 接口：`POST /agent/sessions/{sid}/undo`（`routes/agent.py`，加在文件末尾）
   - 终端：`/undo`（`cli/commands.py`，加在末尾；显示退回了哪些文件、跳过了哪些）
   - 桌面：主进程 `agent:undo`（只认主窗口，照 `agent:merge` 的写法）、preload `agentUndo`；任务页每一轮结尾那一行（`fold.ts` 的 `EndItem`）在「这一轮改过文件、而且是最近一轮、她没在做事」时多一个「撤销这一轮」按钮，点了先在界面里确认一次（列出要退回的文件），结果显示成一条说明
6. 更新 `aila-ai/README.md`「编程 Agent 运行时」和 `aila-desktop/README.md` 任务页一节

## 不要改

- 权限规则（`permissions.py`）
- 已经写进日志的事件（只追加）
- 主窗口的其他页面

## 验收

- 新测试 `aila-ai/tests/test_runtime_undo.py`（用测试里的剧本模型 `Scripted`，见 `tests/test_runtime.py`）：
  - 一轮里改了两个文件、新建了一个：撤销后两个文件字节级恢复（含 CRLF 文件、GBK 文件），新建的被删掉
  - 同一个文件一轮里改了三次：退回到第一次改之前
  - 撤销前用户自己又改了其中一个：那个不动，结果里说明
  - 上一轮的改动不受影响（只撤销最近一轮）；撤销两次第二次说没有可撤销的
  - 撤销后下一轮发给模型的消息：之前的部分和撤销前完全一样（前缀不变），说明在新的那句用户的话前面
  - 撤销后她直接改那个文件会被要求先读
  - 在新分支上做的会话：退的是临时目录里的文件，你的项目目录不受影响
  - 她在做事时撤销被拒绝
- 桌面：`fold.ts` 的测试覆盖「撤销这一轮」按钮什么时候出现
- `AGENTS.md` 里的测试全过
