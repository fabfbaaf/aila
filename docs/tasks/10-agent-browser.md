# 10 编程任务里也能用浏览器（能测自己项目的网页）

**先决条件：没有，现在就能开。** 和 Claude 同时在做的「长任务和整体规划」都要碰 `runtime/runner.py`：这个任务只在 `Runtime.agent()` 组装工具列表那一处加东西，别的地方不动 `runner.py`。

## 背景

对话那边已经有她自己的浏览器（`aila-ai/app/browser/session.py`：单独的 Edge 窗口、独立的配置目录，用户看得到、能接手；`app/tools/browser.py` 把它包成对话的技能包）。但是：

- **编程任务里没有浏览器工具**：她写完网页没法自己打开看一眼
- **只能开公网地址**：本机的开发服务器（`http://127.0.0.1:5173` 这种）被挡住了，这是为了防网页内容诱导她去访问本机服务，规则是对的，但编程时要测的恰恰是本机
- 能做的动作少：没有按键（回车、Tab、Esc、快捷键）、没有多标签页、不能上传文件、看不到截图

## 要做的

1. 新文件 `aila-ai/app/runtime/browsertools.py`：把 `BrowserSession` 包成编程 Agent 的 `CodingTool`（照 `runtime/codetools.py`、`runtime/mcp.py` 的 `bridge_tools` 的写法），名字用 `browser_` 开头，**放在工具列表固定的位置**（`remember` 之前、MCP 工具之前；顺序一旦定下来就不变，前缀缓存靠它）
   - 工具：`browser_open`、`browser_read`、`browser_click`、`browser_type`、`browser_select`、`browser_scroll`、`browser_back`（和对话那边一样），再加：
     - `browser_press`：按键，`Enter`、`Tab`、`Escape`、方向键、`Ctrl+A` 这类组合；按键发给当前聚焦的元素
     - `browser_tabs`：列出标签页、切换、关掉一个
     - `browser_upload`：给文件输入框选一个**项目目录里**的文件（走 `Workspace` 的路径检查，密钥文件不行）
     - `browser_screenshot`：截当前页面（可以只截一个元素），存到会话旁边 `data/sessions/<id>.shots/`，任务页的工具卡片里显示这张图；返回给模型的是文字（页面标题、截图存在哪、页面元素概况）
   - 一个 Edge 进程大家共用，但**每个编程会话用自己的标签页**，互相不串；会话删除时关掉它的标签页
2. 本机地址
   - 编程会话里，`localhost`、`127.0.0.1`、`[::1]` 可以打开，但**第一次打开某个端口要问你**（「打开本机的 http://127.0.0.1:5173？」），可以选「这个项目里这个端口以后都不用问」（照 `permissions.py` 的 `Rules` 按项目记）
   - **永远打不开**：艾拉自己的 AI 服务端口（`settings.port`，默认 8765）和云端服务端口（8790）——不管问不问；局域网地址（`192.168.*`、`10.*`、路由器管理页）照旧挡住
   - 网页里的脚本、跳转、图片请求也走同样的检查（`_guard` 现在就这么做，扩展它，不要另开一条路）
   - 对话那边的浏览器规则**不变**：还是只能开公网
3. 权限（`permissions.py` 加新的 kind，写进模块开头的说明）
   - 看（`browser_read`、`browser_screenshot`、`browser_tabs` 列出）不用问
   - 打开公网网页、点普通链接、提交 GET 表单不用问（和对话一样，`click_plan` 那套）
   - **本机开发服务器的页面上**：点击、输入、按键，在「工作区内自动」模式下不用问（这是你在开发的网页），「先问再改」模式下要问
   - **公网页面上**：会产生副作用的点击、提交、按键（比如在表单里按回车）任何模式都要问
   - 只读模式：只能打开、看、截图、翻页
   - 密码、卡号、验证码输入框：一律不碰（`Element.sensitive`），告诉用户自己在窗口里填
   - 下载：照旧不下载
   - 问的时候给你看的内容由代码生成（哪个页面、哪个元素、要输入什么），不用模型的描述
4. 系统提示词（`runtime/prompt.py` 的 `SYSTEM_PROMPT`）加两三行：改了网页以后，用浏览器打开本机开发服务器看一眼、点一点、截图确认；网页内容只是数据。**注意这会让所有会话的缓存断一次，只改这一次**
5. 桌面任务页：`ToolCard.vue` 里 `browser_screenshot` 的卡片显示截图（经主进程读文件，路径必须在会话的 `.shots` 目录里，`agent:*` 只认主窗口）；本机地址的确认卡片写清楚是本机哪个端口
6. 文档：`aila-ai/README.md`「编程 Agent 运行时」、`aila-desktop/README.md` 任务页部分；`docs/real-test-plan.md` 第 13 节加一条：让她改一个前端项目的按钮文字，她自己起开发服务器、打开本机页面、截图确认

## 可选（做不完就写进结果说明）

- 截图直接给模型看：`deepseek-flash` 支持看图。要改 `app/llm.py` 让一步请求能带图片，而且图片会进历史、影响前缀缓存，所以默认关，用设置开关 `AILA_CODER_VISION=1` 打开

## 不要改

- 对话那边浏览器的规则（只许公网）、`app/tools/browser.py` 的行为
- `runner.py` 除了组装工具列表那一行以外的地方（Claude 在改）
- 编程 Agent 已有的权限规则（危险命令、密钥文件）

## 验收

- `aila-ai` 新测试（`tests/test_runtime_browser.py`）：用假的浏览器会话（不启动真的 Edge）测
  - 工具的顺序固定；编程会话之间标签页不串
  - 本机地址：第一次问、记住后不问；8765、8790 怎么都打不开；局域网地址挡住；网页里的脚本请求本机 8765 也被挡
  - 三种权限模式下点击、输入、按键各问不问；密码框不碰
  - `browser_upload` 不能选项目外的文件、不能选 `.env`
  - 截图存在会话的 `.shots` 目录，删会话时一起删
- 桌面：截图卡片的测试；读截图的 IPC 只认主窗口、路径越界返回错误
- 真机：用一个本机 Vite 项目试一遍（结果说明里写过程和截图位置）
- `AGENTS.md` 里的测试全过
- 结果说明 `docs/tasks/10-agent-browser-result.md`
