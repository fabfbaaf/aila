# 艾拉 · 真实测试计划

第 1–6 周的功能都做完了，自动化测试也都过了（AI 服务 214 个、桌面端 86 个、云端 26 个），但都是用假模型、假网站、程序画的截图测的。这份计划用**真大模型、真麦克风、真网站、真的写代码过程**把每块走一遍：找出问题，顺便攒下简历上能写的数字。

**分工**：密钥、账号、麦克风、登录网站由你来做；遇到问题你在对话里说一声，我看终端日志（aila-ai / aila-server / aila-desktop 三个标签页）定位、修复、补测试。每做完一块打个勾，问题记到最后的表里。

**建议顺序**：0 → 1 → 2 → 6 → 7 → 8 → 3 → 4 → 5 → 9 → 10。先把真模型接通（后面都依赖它），语音最依赖环境，放在中间。每块 10–20 分钟，全部做完大约半天。

---

## 0. 准备（你来做，10 分钟）

- [ ] 申请 DeepSeek 密钥（platform.deepseek.com，充 10 元足够测很久）
- [ ] 可选：博查（open.bochaai.com）或 Tavily（tavily.com，每月 1000 次免费）的搜索密钥。不填的话她只能读你给的链接，不能自己搜
- [ ] 三个服务都在跑：终端面板里的 aila-ai、aila-server、aila-desktop
- [ ] 右键艾拉 →「设置…」→「对话」：填大模型密钥 →「保存并测试」显示连接成功；有搜索密钥的话也填上
- [ ] 准备一副耳机（测语音时对比外放和耳机）

## 1. 基础对话

| # | 做什么 | 期望 |
|---|---|---|
| 1.1 | 双击她，打「你好」 | 1～3 句短回复，有表情和动作（点头、歪头），不出现 `[happy]` 这类标签原文 |
| 1.2 | 问一个技术问题（「Python 的 GIL 是什么」） | 回答拆成短句，气泡按说话节奏出字，出声时口型对得上 |
| 1.3 | 她说到一半，打一句新的话 | 立刻停下，回应新的话 |
| 1.4 | 设置里把密钥改错一位再聊 | 她说「钥匙好像不对」，不会卡在「……」；改回来恢复 |
| 1.5 | 重启桌面端后问「我们刚才聊了什么」 | 记得刚才的话题 |

**记录**：打完字到她开口的时间，感觉一下快慢，大概几秒。

| # | 做什么 | 期望 |
|---|---|---|
| 8.1 | 在 VS Code 的终端里运行一个会报 `TypeError` 的 Python 脚本 | 几秒内她问「好像出错了，要我帮你看看吗？」，摘要是那行 TypeError |
| 8.2 | 点「好」 | 真模型解释原因、给出改法 |
