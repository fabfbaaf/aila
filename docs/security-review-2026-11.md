# 安全总检查（2026-11-17）

范围：本机 AI 服务（谁能调用它）、编程 Agent 的权限、工作区路径、MCP / 浏览器 / 项目记忆 / 计划工具、Electron 桌面端。
云端 `aila-server` 这次没查。分支 `claude/security-review`。

每一条都是先确认问题存在（读代码、实际跑一下），再修，再加测试。

## 发现并修好的

| # | 严重程度 | 问题 | 怎么修的 |
|---|---|---|---|
| 1 | **严重** | AI 服务认 `Origin: null`。任何网站都能用加了 `sandbox` 的 iframe 发出 `Origin: null` 的请求：调 MCP 导入在你电脑上跑任意程序，或者把大模型地址改成它的服务器（之后每次请求都把你的密钥带过去） | `security.py` 不再认 `null`。实测打包后的页面连 WebSocket 时是 `file://`、发 HTTP 不带 Origin，都用不到 `null` |
| 2 | **高** | DNS 重绑定：恶意域名先解析到自己、再解析到 127.0.0.1，它的网页就成了「同源」，Chrome 的同源 GET 不带 Origin，能读会话、代码、记忆 | 加了 Host 检查：HTTP 和 WebSocket 都只认 `127.0.0.1`、`localhost`、`[::1]` |
| 3 | **高** | 编程 Agent 把 `git diff/log/show --output=文件` 当成查看类命令：只读模式下也能写任意文件（`../` 能写到项目外），先问再改模式下也不问 | 带 `--output`、`--ext-diff`、`--textconv` 的不算查看类 |
| 4 | 中高 | 没有 Git Bash、用 PowerShell 跑命令时，`echo @(...)`、`Get-Content (...)` 的括号会先执行里面的命令，却被当成查看类直接跑 | 括号也算「可能执行别的命令」的符号 |
| 5 | 中 | 一些放令牌的文件没认出来：`~/.npmrc`、`.pypirc`、`.netrc`、`.ssh/` 下的所有文件、`.aws/`、`.kube/`、`~/.docker/config.json`、`*.keystore`、`*.jks`。`cat` 它们不问，内容就发给了大模型 | 补进密钥文件的规则（读文件和命令里提到都算，要问、不能「以后都不问」）；项目里自己的 `.docker/` 目录不算 |
| 6 | 中 | 桌面端两个窗口没有 `sandbox`，也没拦跳转和新窗口：要是哪天页面跳到了别的网址，那个网页就拿到了 `window.aila`（能开编程任务、加 MCP 服务） | 两个窗口开 `sandbox`；新加 `main/navigation.ts`：只许显示自己的页面，跳转、重定向、webview、`window.open` 一律拦下 |
| 7 | 中 | 改大模型设置（地址、密钥）、登录登出、删记忆、删资料、删代码库项目、开关技能包这些 IPC 不检查是哪个窗口发的 | 都只认主窗口（设置都在主窗口里）；角色窗口出了问题也改不了这些 |
| 8 | 低 | Windows 设备名（`CON`、`NUL`、`COM1`……）被当成普通文件：读 `CON` 会一直等键盘输入，把工具卡住 | 工作区路径里不许出现设备名 |
| 9 | 低（误伤） | `git log --format=...`、`dotnet format` 被当成「影响整台电脑」的危险命令，每次都问 | `format` 只认格式化磁盘的写法（`format D:`） |

## 查过、没问题的

- 工作区路径：符号链接先解析再判断在不在项目里；`.git` 的各种写法（`.git.`、`.git `、`.GIT`、8.3 短名 `GIT~1`）都挡住；`..`、绝对路径、`\\?\` 前缀挡住；备用数据流挡住
- 所有 GET 接口都只读（`GET /agent/mcp` 会启动你自己配置的 MCP 服务，可以接受）
- 她回答里的链接只显示、不能点；用 `v-html` 的两处都先整段转义
- MCP 服务子进程拿不到艾拉自己的密钥；服务只有你能加；工具结果当数据
- 编程浏览器：每次真实连接都按地址规则检查，艾拉自己的端口和局域网打不开（合并 10 时已实测）
- 撤销一轮的还原检查（07 合并时审过）

## 已知、暂时不改的

- **读项目外的文件不问**：命令能 `cat` 项目外的文件（密钥文件除外）。这是「读不用问」的设计，内容会发给大模型
- **项目记忆在「工作区内自动」模式下不问**：网页、文件内容理论上能诱导她记下一句话带进以后的会话。记下的话在任务页右边看得到、删得掉
- **其余 IPC 没查发送方**：对话、语音、历史这些角色窗口要用，查看类的数据接口两边都用，风险低
- **Windows 上跑命令没有沙箱**：命令真正能做什么只能靠权限规则把关，危险命令的识别是尽力而为
- **页面的 CSP 允许连接任意 `ws:` 地址**：渲染层自己只连本机的语音、看屏幕两个 WebSocket
- **云端 `aila-server`** 这次没查，下次单独查（登录、令牌、同步接口）
