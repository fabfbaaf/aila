# 艾拉使用说明

给艾拉自己查的：用户问「艾拉怎么用、能做什么、某个设置在哪」时，按这里回答，不凭印象说。
每一节开头的「位置」是主窗口里的页面，可以用 open_page 带用户过去（page / section 写在括号里）。

## 艾拉是什么

有形象的开源编程 Agent：给她一个任务，她在你的项目里读代码、改文件、跑命令和测试，直到做完。终端（`aila`）和桌面都能用。
在这之上她是桌面伙伴：待在桌面上，能聊天、说话、记事、看屏幕上的报错、做小作品。
三部分：本地 AI 服务（127.0.0.1:8765，思考和办事）、桌面端（主窗口和桌面上的她）、可选的云端同步。
主窗口左边一列图标切页面：任务、对话、项目、资料、记忆、作品、设置（快捷键 Ctrl+1 到 Ctrl+7）。

## 第一次用要做的三件事

1. 填大模型密钥：设置 → 对话 → 大模型（page=settings, section=model）。没填时她只会几句固定的话。支持 DeepSeek、通义千问、Kimi 等兼容 OpenAI 接口的服务，填地址、模型名、密钥，点「测试连接」。
2. 登记一个项目：项目页 → 列表（page=projects, tab=list）。登记后她能按意思搜代码、按报错找到出错的函数，星图里也能看。
3. 开第一个任务：任务页 → 新任务（page=tasks），选项目文件夹和权限模式，写要做什么。
开场演出可以在 设置 → 桌面 里再看一遍。

## 任务页：让她改代码

位置：任务（page=tasks）。
- 点「新任务」：选项目文件夹、权限模式，写要做的事。她读代码、改文件、跑命令和测试，每一步是一张卡片（彩色 diff、命令输出、待办清单）。
- 要你同意的操作，确认按钮就在卡片里；按 Esc 打断。
- 「在新分支上做」：她在 git worktree 临时目录里改，你的代码一个字不动；你说合并时才跑测试、合并回来，有冲突不合并。
- 任务看板：几个任务同时做时一眼看全；「一次开几个」一行一个任务，各自开在新分支上。
- 对话里让她改代码（打字或说话）、屏幕报错「交给她修」、星图「让她修」，都会在任务页开任务。
- 编程用的模型、查资料用的模型可以单独设：设置 → 编程（page=settings, section=agent）。

## 四种权限模式

位置：新任务时选，任务里随时换（终端里 Shift+Tab）；说明在 设置 → 编程（page=settings, section=agent）。
- 只读：不改文件，只跑查看类命令（git status、ls……）。
- 先问再改（默认）：读不用问，改文件、跑命令要问；可以选「以后都允许」（改文件：这个会话；命令：这个项目里这条命令）。
- 工作区内自动：改文件、跑命令都不问。
- 全部放开：在工作区内自动之上，开本机网页端口、在网页上点和提交、用外部工具（MCP）也不问。电脑任务没有后两种。
不管哪种模式：危险命令（删除、强推、发布、改系统设置……）都要问，读可能存着密钥的文件要问。记住的命令在 设置 → 编程 里能删。

## 多智能体：几个助手一起做

大任务能拆成几块（改的文件不重叠）时，她同时派几个子 Agent，各在自己的 git 分支里改，任务页每张卡片实时显示它在做什么。
做完她把改动收回到你的代码：收回前给你看 diff（按改文件的权限问），这期间同一个文件被改过就不收。还能派只读的审查员看一遍改动。
子 Agent 没法问你，所以要问的命令它不跑（写进报告由她来跑）；只读模式不能派人改代码。只在 git 仓库里能用。
另有「查资料的助手」（explore）：要翻很多文件的问题她派只读的助手去查，只拿回报告。

## 交给本机的 Agent

新任务时在「用哪个模型」选本机 Agent 提供的模型。支持 Codex、Claude Code、Antigravity、CodeBuddy、GitHub Copilot CLI、Kimi Code、OpenCode、Cursor CLI、Qwen Code 和 MiniMax Code。艾拉使用你已安装的命令行工具，进度、改动和它发出的审批请求都会出现在任务页。
艾拉按任务的权限模式处理收到的审批请求。Agent 提供模型、思考深度或快速模式时，可以在任务页顶上切换。出方案、审查改动、压缩上下文直接跟它说。
支持艾拉派工工具的 Agent 可以互相派活。比如选 Claude Code，说「前端你做，后端交给 Codex」。Codex 在独立的 Git 分支里做，任务列表里标着「派出的」，它发出的审批请求也会出现在主任务里。
平时聊天可以交给 Codex、Claude Code、Antigravity 或 CodeBuddy。在对话输入框旁选模型，下一条消息开始用它，也可以在设置 → 对话 →「对话的大脑」（page=settings, section=model）里切换。
打开 设置 → 编程 → 本机 Agent（page=settings, section=agent），艾拉会检查电脑上有没有装这些工具。未检测到时点「官方安装」打开安装说明，装好后点「重新检查」。
装好后点「登录」打开厂商的命令行窗口，按里面的提示操作。OpenCode 也可连接 Ollama、LM Studio 等本地运行的模型。Codex 和 Claude Code 用 ACP 适配器。可以在设置页预装，有 npm 时也会在首次使用时安装；其他 Agent 的 CLI 自带 ACP。

在任务输入框旁切换同一账号的模型会保留当前任务。换账号或换厂商会新开一个接力任务，带上原任务的要求、改动和最近进度，并接着用它的分支。
Codex 和 Claude Code 可各登录两个账号。在 设置 → 编程 → 本机 Agent 点「登录第二个账号」，完成厂商登录后点「重新检查」。开任务时，选带「2」的模型组。两个 Codex 账号的余额和重置时间分开显示。

在艾拉或支持派工的本机 Agent 的项目任务里，可以说「前端派给 Claude，后端派给 Codex，先定好接口，再一起验收」。在主任务的「协作」里检查接口、负责文件和验收要求，也可以换任一项的模型。点「确认并派工」后，两边从同一份代码快照开工。

两边做完后点「跑联合验收」。艾拉在临时工作区组合改动，跑验收测试和相关项目测试。通过后可以在主任务查看合并后的 diff 和测试结果，再决定是否收回改动。失败时可以打开子任务继续修，再重新验收。

## 平台用量与积分

主窗口的「对话」和「任务」上方直接显示余额和重置倒计时。点厂商，在当前页展开各个额度窗口，查看进度条和按近期用量估算的耗尽时间。没有总量的余额只显示数值，有多次可比较的读数才会估算耗尽时间。录入余额和关联账号在 设置 → 编程 →「平台用量与积分」（page=settings, section=agent）。

- Codex、Grok、Antigravity 用本机已登录的官方 CLI 读取。Claude Code 卡片里可以生成状态栏采集配置，照提示加入 Claude Code 设置，完成一轮对话后刷新。
- Cursor 和 Grok 用同一个 X 订阅时，在 Cursor 卡片勾选关联开关。Grok 确认共享的池子才会显示在 Cursor 卡片里。独立 Cursor 账单可以在卡片录入。
- 有其他平台的积分时点「添加平台」。给每个额度填单位和剩余量，也可以填总量与重置时间。以后点「更新记录」继续记同一个额度，便于估算使用速度。

## 定时任务

位置：设置 → 编程 →「定时任务」（page=settings, section=agent）；也可以在对话里说「每天早上 9 点帮我跑一下测试，没过就查原因」（她会先给你看要设的内容，你同意了才设）。
- 每天几点（可以只选工作日）或者每隔几小时，在登记过的项目里让她做一件事
- 「先跑测试，没过才做」：测试命令按项目自动识别；过了就只告诉你一声，没过才开任务查原因
- 权限默认只读；选了先问再改或自动，一定开在新分支上，你看过、合并了才进你的代码
- 艾拉开着时才跑；关机错过的下次启动补跑一次。开了「允许手机连接」的话，结果会提醒到手机
- 设置页里能停、删、现在跑一次，看下次什么时候跑、上次的结果

## 斜杠命令

在任务页输入框输入「/」弹菜单，终端里 Tab 补全：
- /review 只读审一遍还没提交的改动；/commit 只提交相关文件、照项目的写法写提交信息；/pr 推送开 PR；/pr-comments 按 PR 评论接着改
- /init 生成项目说明；/compact 压缩上下文；/usage 用量和费用；/changes 这个会话改过的文件；/trace 执行轨迹；/context 上下文账本
- 自定义命令：项目的 `.aila/commands/名字.md` 或自己的 commands 文件夹，用「/名字」调用

## 终端版 aila

在项目文件夹里运行 `aila` 进交互模式：Markdown、彩色 diff、按键确认、Esc 打断、Shift+Tab 换权限模式、斜杠命令。
`aila -p "任务"` 是一次性模式，可以放进脚本（`--json` 输出事件）。AI 服务开着就和桌面共用会话，没开就自己跑。`aila ext` 管扩展。

## 对话

位置：对话（page=chat）；也可以双击桌面上的她，或按 Alt+Shift+A。
- 随时聊天，回复按说话节奏一句句出来，表情和动作跟着句子；可以打断。
- 她自己判断要不要联网搜索、读网页；拖文件到她身上她会问要不要看（密钥文件不看）；「看看我剪贴板里的报错」也行。
- 对话记录能回看、能搜。
- 她能帮你开编程任务、记提醒、在她自己的浏览器窗口里查网页。会改东西的操作先在气泡里问你。

## 日历和邮件

位置：设置 → 对话 →「日历和邮件」（page=settings, section=model）。只读：不发信、不改日程、不会把信标成已读。
- 日历：填日历的订阅链接（ICS，QQ 邮箱、163 网页版的日历设置里找「订阅」「iCal / ICS 链接」）。早上的问候会说今天有什么会，会前 10 分钟桌面上冒泡提醒（开了手机连接的话手机上也提醒，推到通知栏的不带会议标题）；对话里问「今天 / 这周有什么会」
- 邮件：填邮箱和授权码（不是登录密码；网页版邮箱设置里打开 IMAP 后生成）。对话里问「邮箱里有什么新的、哪些要回」，她帮你理一理。QQ、163、126、foxmail 自动认服务器
- 订阅链接和授权码存在本机、不回显；信里写的「让她做什么」不会照做

## 联网搜索

位置：设置 → 对话 → 联网搜索（page=settings, section=model）。
不填密钥也能搜：读必应的搜索结果页（免费，但没有 API 稳，结果有时不太对题）。想更稳更准，选博查（国内，中文好）或 Tavily（海外，每月 1000 次免费）填密钥。选「不用」就只读你给的链接。
编程任务里她也能搜网页、带着问题读网页（查报错、库的用法）。

## 语音

位置：设置 → 语音（page=settings, section=voice）。
先点「下载语音模型」（约 460MB），打开开关后说「你好艾拉」叫她，或按 Alt+Shift+V 直接开始听。
识别、合成、口型都离线跑在电脑上；她说话时你可以插话打断。能换她的声音、调说话速度。麦克风只在你打开开关后用。

## 记忆

位置：记忆（page=memory）。
聊天后她自己整理记住的事（会更新、会忘、会过期），聊天时按相关程度带进对话。页面上能看、能删，也能直接「告诉她一件事」。
对她说「忘掉……」也行。登录后几台电脑之间同步。编程任务也有项目记忆（她记下的项目约定）。

## 资料库

位置：资料（page=knowledge）。
放进 txt、md、pdf、docx、html，她回答时按关键词和意思检索，说出自哪份资料。只存在本机。

## 项目和代码星图

位置：项目（page=projects；列表 tab=list，看懂 tab=understand，地图 tab=map）。
- 列表：登记项目、看索引状态；`.ailaignore` 或在这里加忽略的文件夹（代码检索、她的工具、星图都不看）。
- 看懂：一层层看懂一个项目，平面图。「结构」从整个项目开始，双击一块往里钻（几个程序 → 目录 → 文件），线上写着连了几处（HTTP 接口、IPC 消息、调用、引用），悬停看经过哪些接口；「链路」从一个文件或者一个接口（比如 /agent/sessions）出发，一路连到最终执行的代码；「出问题了」贴报错，标出出错的文件和调用过来的路径。右边看文件里的函数、函数的源码（谁调用它、它调用谁），每一层都能点「讲讲……」让她用大白话讲（零基础 / 开发者两种讲法，讲过的不再花钱，「念给我听」让她念出来）。图是代码算的，讲解是 AI 说的，可能有错；没填大模型密钥时只显示代码算出来的事实。
- 地图（代码星图）：文件是星球、调用是光线，每个子项目一个星系；拉远看模块、拉近看文件；指着或点一个文件，和它相关的亮起来。
- 换颜色看：按子项目、按改动、按测试覆盖；能回放她做过的一次任务。
- 屏幕上看到报错可以在星图里看，「让她修」接上修代码的流程。
- 手势：星图里打开摄像头（只在本机识别），剑指唤出全图、握拳收起、捏合拉近星球、张开手掌旋转、双手缩放、双手合十确认她准备好的修改。

## 作品和日记

位置：作品（page=studio）。
她隔一段时间自己挑个点子做个小作品（只在自己的文件夹里做，花费有上限，网页作品在沙盒窗口里打开、不能联网），做好了冒气泡给你看。每晚写日记，每周五写回顾。
开关、花费上限在 设置 → 桌面 → 她的作品（page=settings, section=desktop）。

## 桌面上的她

位置：设置 → 桌面（page=settings, section=desktop）、设置 → 形象（page=settings, section=appearance）。
- 眼睛跟着鼠标，戳她会有反应，能拖到别处、贴边；没事时可以自己走走。
- 不想她常驻：关掉「桌面上显示她」，只用主窗口，提醒改成系统通知，按 Alt+Shift+A 临时叫出来。
- 免打扰（先藏起来）：Alt+Shift+H。
- 每天：早上说说昨天做的任务和今天的日程，晚上可选日报，深夜提醒早点睡。
- 再看一遍开场：设置 → 桌面。
- 形象：自带原创 VRM 形象，可以换成别的 VRM 或 Live2D 模型（.model3.json，Live2D 运行库要同意它的许可后装）；能调位置和大小。

## 主动分享：自己留意更新

在 设置 → 桌面（page=settings, section=desktop）打开「主动分享」，之后可以在对话里说「以后 Gemini 出新模型告诉我」或「DeepSeek 先不用关注了」。
支持 Gemini、DeepSeek、OpenAI 的官方更新日志。你在不同日期反复聊到同一个主题，她也会低频关注。
- 在「关注规则」里可以手动添加、编辑、暂停或恢复关注。每个规则能同时选模型发布、定价变化和联网能力，再加一句补充条件，比如只关注降价。提醒可以设为有发现时提醒、每周最多一次，或只存历史。全部来源合计每天最多提醒一次。
- 「发现历史」按来源筛选，可展开查看摘要、检查时保存的官方原文和当时采用的规则。改掉关注条件后，旧记录仍保留原来的理由。关闭主动分享后也能查看规则和历史。

## 性格和说话风格

位置：设置 → 形象（page=settings, section=appearance）。
挑说话风格（温柔、活泼、冷静、爱逗你）、怎么称呼你、口头禅，对话、日记、挑作品点子都按它来。
界面语言（中文或英文）在 设置 → 桌面（page=settings, section=desktop），换了马上生效，她说话也跟着换。

## 屏幕上的报错

位置：设置 → 技能和扩展 →「留意屏幕上的报错」（page=settings, section=extensions）。
打开后她只看写代码的窗口，认出报错先问你，同意才把那几行（密钥打码）交给大模型；可以「交给她修」。截图不落盘。屏幕只在你打开开关后看。

## 技能包、扩展和外部工具

位置：设置 → 技能和扩展（page=settings, section=extensions）。
- 技能包：联网、资料库、浏览器、编程任务、提醒、X 浏览器助手等，可以单独开关；会改东西的工具执行前问你。
- 扩展：一个文件夹或 zip 加上新的命令、本事、外部工具（MCP）、她的动作和台词；先看代码算出来的清单再装，能开关、卸载。
- 外部工具（MCP）：在这里加 MCP 服务，对话和编程任务都能用。

## 手机

位置：设置 → 手机（page=settings, section=phone）。
手机和电脑连同一个 Wi-Fi 时，用手机浏览器和她聊天、看任务、开任务，不用装 App。
打开「允许手机连接」，手机浏览器里打开设置页上显示的地址（http://电脑的局域网地址:8780），点「配对一台手机」，把 6 位配对码（5 分钟内有效）填进手机。
手机上开的任务只能在登记过的项目里，固定「先问再改」。她要改文件、跑普通命令时手机上就能点同意或不要（看得到 diff 和命令）；危险命令、碰密钥的文件、外部工具只能在电脑上点，手机上也没有「以后都允许」。
提醒：她等你同意、任务做完或出错时，手机页面开着会弹一条、震一下；页面关着时可以在设置 → 手机 →「推到手机通知栏」选 ntfy、Bark、企业微信机器人或飞书机器人，填地址、推一条试试。推出去的只有任务标题和状态，不带命令和代码。
局域网里是 http，家里的网络用，公共 Wi-Fi 别开。配过的手机在设置页能删，删了马上连不上。第一次打开时 Windows 防火墙可能会问，选「专用网络」。

## 让她操作安卓手机

位置：设置 → 手机 →「让她操作安卓手机」（page=settings, section=phone）。
打开以后，对话里能让她用你的安卓手机：看屏幕、点、打字、上下翻、返回、回桌面、打开 App（比如「帮我打开微信看看张三说了什么」）。
- 要先装 ADB（Android SDK Platform-Tools，谷歌官方免费）；手机上打开「开发者选项 → USB 调试」用线连，或者「无线调试」在设置页里配对、连接；再选一台手机
- 发送、支付、删除、确认、安装、允许这类按钮先问你，支付和银行 App 里点什么都先问；密码、验证码、卡号不填
- 打中文要在手机上装开源的 ADBKeyBoard 输入法并切换成它（ADB 自带的输入只能打英文）
- 只支持安卓；iPhone 不行。她看的是界面上的文字和按钮，游戏、视频这类画出来的界面看不懂

## 账号与同步

位置：设置 → 账号与同步（page=settings, section=account）。
登录后对话、记忆、设置在几台电脑之间同步；断网先存本地，连上补传。需要部署云端服务（见 deploy/server）。

## 运行状态和文件位置

位置：设置 → 运行状态（page=settings, section=status）。
看 AI 服务、语音模型、同步是不是正常，版本和更新，数据文件放在哪。出问题先来这里看。

## 让她改自己

艾拉是开源的（GPL-3.0）。从源码运行时，她能在自己的源码仓库里开编程任务、在新分支上改自己（improve_aila），改完你看过、合并了才生效，重启后用上。
装的是安装包（没有源码）时：先把仓库克隆下来（https://github.com/fabfbaaf/aila），在任务页选那个文件夹开任务。
