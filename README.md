# 艾拉 · 程序员的 AI 桌面伙伴

有 3D 形象的开源编程 Agent：像 Claude Code 一样，给她一个任务，她在你的项目里读代码、改文件、跑命令和测试，直到做完；终端和桌面都能用。
在这之上，她常驻桌面：看着你的鼠标、被戳会害羞；叫一声「你好艾拉」就能和她说话；看到报错主动帮忙；还有用手势操控代码的「魔法工作台」。

## 当前进度

编程 Agent（核心）：

- [x] 运行时：会话是只追加的事件日志（终端和桌面看同一份，中断后能接着做）；读、找、搜、改、写文件和跑命令的工具；只读 / 先问再改 / 工作区内自动三种权限，危险命令始终要问；按 DeepSeek 前缀缓存排布上下文，每一步记下缓存命中；打断、上下文压缩、钩子；HTTP 接口
- [x] 终端版 `aila`：交互模式（Markdown、彩色 diff、命令输出、待办清单、每轮统计和缓存命中率）、按键确认、Esc 打断、Shift+Tab 换权限模式、斜杠命令（/resume /compact /usage /changes /init……）；一次性模式 `aila -p` 可以放进脚本（`--json` 输出事件）；AI 服务开着就和桌面共用会话，没开就自己跑
- [x] 主窗口「艾拉」的任务页（原来的工作窗口）：会话列表（终端里开的也在）、每一步的工具卡片（彩色 diff、命令输出、待办）、卡片里直接确认、Esc 打断、待办 / 改过的文件 / 缓存命中率；桌面上的她用动作和语音汇报（开始、要确认、做完）；编程用的模型可以单独设
- [x] 执行轨迹和上下文账本：每一轮按时间画出每一步（她在想多久、等第一个字多久、每个工具多久、等你确认多久、每一步命中多少缓存）；上下文由哪几块组成、开头固定的几块命中缓存、离压缩还有多远、谁最占地方。任务页和终端（`/trace`、`/context`）都有
- [x] 接上已有能力：代码 RAG 和调用图成了她的工具（按意思搜、按报错定位、看谁调用了谁）；屏幕上的报错「交给她修」、星图「让她修」、对话里（打字或说话）让她改代码，都会在任务页开任务；星图里她读的文件闪一下、改过的变绿，双手合十能确认她的改动；「在新分支上做」：她在 git worktree 里改，你的代码不动，合并前跑测试、查冲突
- [x] 查资料的助手和模型分工：要翻很多文件的问题她派只读的助手（子 Agent）去查，只拿回报告，几个一起跑；助手用便宜的「查资料用的模型」，她自己用「编程用的模型」（按角色分，不按步骤换，缓存才不断）
- [x] 后台命令：开发服务器、watch 这类不会自己退出的命令放到后台跑，随时看输出、停掉；打断一轮不停它们，关服务时连子进程一起清掉（Windows 用 Job Object）
- [x] 电脑任务：不选项目、用命令行操作这台电脑，只有只读和先问再改两种模式，受保护的位置每次都问；对话里一两步的小事直接做
- [x] 自定义命令：项目 `.aila/commands/` 和自己的 `commands/` 里的「名字.md」用「/名字」调用；终端补全，任务页输入「/」弹菜单
- [x] 任务看板：几个任务同时做时一眼看全（等你、在做、做完了、卡住了），卡片上直接同意、停下、打开；「一次开几个」一行一个任务，各自开在新分支上
- [x] 交活：`/commit` 只提交相关文件、照项目的写法写提交信息；`/pr` 推送开 PR；`/pr-comments` 按 PR 评论接着改（评论只当数据）
- [x] 项目里忽略文件夹：`.ailaignore` 或者在项目页里加，代码检索、她的工具和星图都不看（比如评测用的示例项目）
- [ ] 评测：25 个任务（修 bug、加功能、重构、看报错、只读、写测试，Python 和 JS）和打分都准备好了——隐藏测试、改测试算作弊、只读任务不许改文件、每个任务的参考答案都验证过；报告有成功率、步数、费用、缓存命中率、按类别统计和每次的会话日志。还差用真模型跑一遍出数字

桌面伙伴和魔法工作台：

- [x] 透明置顶桌面窗口，鼠标只在角色身上生效，其他地方穿透到桌面
- [x] VRM 3D 角色：待机呼吸眨眼、视线跟随全屏鼠标、点击反应、拖动贴边、犯困
- [x] 文字对话：流式回复按说话节奏输出，表情和动作与对应句子同步，可打断
- [x] 联网搜索和网页阅读：她自己判断要不要查，查的时候气泡显示进度；读链接有 SSRF 防护（开着代理的 fake-ip 模式也拦得住）
- [x] 语音：唤醒词「你好艾拉」、断句、识别、按句合成、五个元音口型同步、插话打断、回声过滤，全部离线跑在 CPU 上
- [x] 账号与多设备同步（Spring Boot）：注册登录，对话和设置在几台电脑之间实时同步；断网先存本地、连上补传，断线重连补拉，不丢不重
- [x] 长期记忆：聊天后她自己整理记住的事（会更新、会忘掉、会过期），按相关程度带进对话，多设备同步，删除优先不会被复活
- [x] 个人资料库：放进 txt/md/pdf/docx/html，关键词和语义混合检索，回答时说出自哪份资料；只存在本机
- [x] 技能包框架：联网、资料库、外部 MCP 服务都是技能包，可以单独开关；会改东西的工具要你确认
- [x] 主窗口「艾拉」：以前的工作窗口、代码星图、设置三个窗口合成一个，左边图标切任务、项目（列表 + 地图）、资料、记忆、设置；托盘图标，只开一个；大模型和密钥、语音、技能包、账号、形象、运行状态都在设置页里改，保存立刻生效
- [x] 她知道你在忙什么：每天第一次见面说说昨天做的任务、没合并的分支、今天的日程；晚上可选日报；对话记录页能回看、能搜
- [x] 拖文件给她、剪贴板：拖到她身上就问要不要看（密钥文件不看、内容打码），在仓库里的还能交给任务页；「看看我剪贴板里的报错」
- [x] 新动作：挥手、伸懒腰，做编程任务时在桌面上「敲键盘」
- [x] 她的作品和她的一天：隔一段随机的时间她自己挑个点子写个小作品（只在自己的文件夹里做、花费有上限、网页作品在沙盒窗口里打开，不能联网），做好了冒气泡给你看；作品页看作品和日记；每晚写日记；记得认识第几天、过节；早上说说昨天做了什么、今天的日程；深夜提醒早点睡
- [x] 小情绪和性格：跑测试过了会高兴，连着挂会叹气、给你打气；设置里挑说话风格（温柔、活泼、冷静、爱逗你）、怎么称呼你、口头禅，对话、日记、挑作品点子都按它来
- [x] 原创形象：代码生成的 VRM 1.0（银紫波波头、连帽卫衣、「▍」光标发夹和「>_」提示符），随程序自带；表情、口型、眼睛跟着鼠标都有
- [x] 对话也按前缀缓存排：系统提示词固定，日期和记忆跟着最新一句，历史一次丢一批
- [x] 操作确认：会改东西的工具执行前她先问，气泡里显示要做的具体内容（由代码从参数生成），点按钮、打字或说「好 / 不要」；打断、超时、听不懂都不执行。第一个用上它的是「在浏览器里打开网页」
- [x] 网页操作：她用自己的 Edge 窗口（独立配置，你看得到）去网页上搜索、点链接、填表；按 HTTP 语义分风险——只产生 GET 导航的直接做，点按钮、提交 POST 表单先问你；密码、验证码不碰；所有请求只许公网地址
- [x] 屏幕感知报错：只看写代码的窗口，画面变化检测 → 只识别变了的几行（本地 OCR）→ 规则认报错 → 先问你，同意才把那几行（密钥打码）交给大模型；每层过滤多少都有计数，截图不落盘
- [x] 魔法工作台 · 代码 RAG：tree-sitter 按函数切块（Python / Java / TS / Vue），三路检索（名字、关键词、向量）+ 往文件里细找，按报错堆栈定位到函数再沿调用图找上下文，增量更新；有评测脚本和消融对比，代码只在本机建索引
- [x] 魔法工作台 · Agent 修代码：先给你看 diff（代码算的，不是大模型说的），同意后用 git worktree 在新分支上改、跑项目自带的测试（命令按项目识别，不由大模型决定），全过才改到你的代码里，没过自动撤回；你没提交的改动原样带进测试，测试期间你改过的文件不覆盖
- [x] 魔法工作台 · 3D 代码星图：文件是星球、调用是流动的光线，每个子项目一个星系；点星球看函数和代码、问她；屏幕上看到报错可以直接在星图里看，出错的星球变红、调用链变橙，「让她修」接上修代码的流程
- [x] 星图分三层（星系、模块、文件，拉远看模块、拉近看文件）；前后端之间的 HTTP、IPC 画成弧线；import 关系参与布局，用到的第三方库是外圈的恒星（点一下看谁在用），文件面板列出引用了谁、被谁引用
- [x] 星图换颜色看项目：按子项目、按改动（越常改越红）、按测试（有没有测试覆盖）；回放她做过的一次任务：按步重放读了哪些文件、改了哪里，时间轴能拖
- [x] 魔法工作台 · 手势操控：星图里打开摄像头（只在本机识别，MediaPipe），剑指唤出全图（法阵特效）、握拳收起、捏合抓星球往面前拉看代码、张开手掌旋转、双手缩放、双手合十确认她准备好的代码修改（只能确认修代码这一种）

用真大模型、真麦克风、真网站把各项走一遍的计划：[docs/real-test-plan.md](docs/real-test-plan.md)。

## 仓库结构

```
aila-desktop/   桌面端：Electron + Vue 3 + Three.js（@pixiv/three-vrm）
aila-ai/        本地 AI 服务：Python + FastAPI，调用大模型、工具调用（搜索、读网页）、解析表情动作标签、语音（sherpa-onnx）
aila-server/    云端后端：Java 21 + Spring Boot 4 + PostgreSQL，账号和多设备同步
```

三种语言各管一层：桌面端负责表现，本地 AI 服务负责思考和办事（语音不出本机），云端负责账号和数据。

## 快速开始

**直接装**：Windows 上用安装包（`艾拉 Setup 版本号.exe`，自己打包见 [aila-desktop/README.md](aila-desktop/README.md)「打包」）。双击安装，开始菜单里点「艾拉」，不用装 Python、Node；AI 服务在安装包里，由桌面端启动。装好后在「设置 → 对话」填大模型密钥，语音模型在「设置 → 语音」里点「下载语音模型」（约 460MB）。安装包没有代码签名，Windows 会提示「已保护你的电脑」，点「更多信息 → 仍要运行」。

**从源码跑**：需要 Node.js 20+、Python 3.11+；用同步功能还要 Java 21。

```powershell
# 1. 本地 AI 服务
cd aila-ai
py -3.12 -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python scripts\download_models.py   # 语音和向量模型，约 470MB
.venv\Scripts\python -m app     # 监听 127.0.0.1:8765；没填大模型密钥时用内置假模型

# 2. 桌面端（另开一个终端），然后右键艾拉 →「设置…」→「对话」填大模型密钥
cd aila-desktop
npm install
npm run dev

# 3. 可选：云端同步（另开一个终端），然后「设置…」→「账号与同步」登录
cd aila-server
.\mvnw spring-boot:test-run     # 内嵌数据库，不用装 PostgreSQL；监听 8790
```

她的原创形象随仓库自带（`aila-desktop/src/renderer/public/avatar/aila.vrm`，由脚本生成），也可以换成任何 VRM 模型，见 [aila-desktop/README.md](aila-desktop/README.md)。

## 架构

```
┌──────────────── 你的电脑 ────────────────┐
│  aila-desktop（Electron）                │
│    渲染层：3D 角色、气泡、麦克风；主窗口 │
│    主进程：窗口、转发对话、同步、记忆    │
│                 │ HTTP + SSE、WebSocket  │
│  aila-ai（FastAPI，只监听本机）          │
│    对话：人设、技能包和工具、标签解析    │
│    记忆挑选和整理、资料库检索、MCP       │
│    语音：唤醒、断句、识别、合成          │
└──────────┼───────────────────┼───────────┘
           │ OpenAI 兼容接口   │ HTTPS（只许公网地址）
    大模型（DeepSeek 等）   搜索服务（博查/Tavily）、网页

桌面端主进程 ── REST 上传、按序号拉取 ──▶ aila-server（Spring Boot）── PostgreSQL
             ◀─ WebSocket「有新变更」─── 账号、对话、记忆和设置同步
```

各部分的设计说明见子目录的 README。
